# Fly Trading — 초파리 뇌가 NVDA를 매매하는 릴스

## 목표
실제 초파리 커넥톰 시뮬레이션이 NVDA 매수/매도를 결정하고, 그 결과를 세로 릴스 영상(1080×1920, 30fps, ~30초)으로 보여준다.
정교한 트레이딩이 아니라 "진짜 뇌가 결정한다"는 걸 시각적으로 보여주는 게 목적. 실제 주문은 없다(과거 데이터 모의매매).

## 데이터
- 연결 데이터: Shiu et al. 2024 (MIT) — `2023_03_23_completeness_630_final.csv`, `2023_03_23_connectivity_630_final.parquet` (FlyWire v630, 논문 검증 버전)
- 입력/출력 뉴런: 논문 figures.ipynb의 단맛 GRN 21개, 쓴맛 GRN 21개, MN9 (`720575940660219265`)
- 3D 좌표: FlyWire `Supplemental_file1_neuron_annotations.tsv` (v783, pos_x/y/z). v630 ID의 83%가 매칭됨 — 시각화 전용
- 주가: yfinance NVDA 일봉, 최근 약 60거래일
- 데이터 파일은 git에 넣지 않고 `data/`에 다운로드

## 구성 (`flytrade/`)
| 모듈 | 역할 |
|---|---|
| `data.py` | 커넥톰·좌표·주가 다운로드/로드 |
| `brain.py` | 논문 LIF 모델의 numpy 재구현. 파라미터 동일 (v0=-52mV, vth=-45mV, τm=20ms, τg=5ms, 불응기 2.2ms, 지연 1.8ms, w=0.275mV, Poisson 가중치 ×250). dt=0.1ms, 스파이크가 난 뉴런의 행만 sparse 전파 |
| `trader.py` | 최근 5일 상승폭 합 → 단맛 Hz, 하락폭 합 → 쓴맛 Hz (0–200Hz). MN9 발화율 ≥ 임계값이면 보유(매수), 아니면 현금(매도). long-only, 전액 진입/청산. `output/timeline.json` 출력 |
| `intro.py` | 3D 뇌 포인트 클라우드 글로우 렌더 + 단맛→MN9 신호 전파(첫 스파이크 시각 순서로 뉴런 점등) |
| `overlay.py` | 투명 오버레이: 상단 티커/수익률, 하단 차트(매수/매도 마커), 구석 뇌 HUD(단맛·쓴맛·MN9 미터), BUY!/SELL! 팝업, 엔딩 카드(초파리 vs 존버) |
| `video.py` | 인트로 + (AI 클립 배경 + 오버레이) 합성 → `output/reel.mp4`. `assets/clips/{idle,buy,sell,win}.mp4`가 없으면 자리표시 프레임 자동 생성 |

## 영상 타임라인
- 0–3초: 인트로(뇌 회전 → 신호 전파 → 플래시)
- 이후: 거래일당 ~0.3초로 차트 진행. 매매 이벤트마다 차트를 멈추고 해당 클립(~1.8초) 재생, 그 외엔 idle 루프
- 마지막 ~2.5초: 엔딩 카드

## 검증
- `brain.py`: 단맛 자극 시 MN9 발화, 쓴맛 동시 자극 시 MN9 감소 (논문 Fig 3A 정성 재현)
- `trader.py`: 가짜 뇌 함수로 매매 규칙/수익 계산 단위 테스트
- `video.py`: 세그먼트 타임라인 계산 단위 테스트, 실제 렌더 후 프레임 육안 확인

## 범위 밖
실시간 매매, 실제 주문, 오디오/BGM(릴스 편집기에서 추가), 여러 종목.
AI 클립 프롬프트는 코드 완료 후 "영상 만들기" 단계에서 작성.
